# Security

This project has no supported production release or security response SLA yet.
Do not put tokens, tenant data, scripts containing secrets, or exploit details in
public issues. A dedicated private reporting channel has not been configured;
arrange a private channel with the maintainer before sending sensitive details.

Sensitive schema flags redact displays; they do not encrypt Terraform state.
Protect state and keep credentials in your existing secret-management workflow.
Report the affected version and a sanitized synthetic reproduction when possible.
